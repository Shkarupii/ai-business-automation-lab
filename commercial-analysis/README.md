# Commercial Analysis

AI-assisted підхід до аналізу закупівель та продажів компанії.

## Що аналізуємо

- обсяг продажів;
- обсяг закупівель;
- товари та категорії;
- постачальників;
- покупців;
- закупівельні та продажні ціни;
- маржинальність;
- націнку;
- оборотність;
- мінімальні вигідні партії закупівлі.

## Підхід

**Excel / CSV → AI-assisted analysis → очищення даних → сегментація → висновки → управлінські рішення**

## Мета

Перетворити звичайні таблиці продажів і закупівель на зрозумілу систему для прийняття комерційних рішень.

## Майбутні модулі

- ABC / XYZ аналіз;
- аналіз маржинальності;
- рейтинг постачальників;
- рейтинг покупців;
- аналіз закупівельних цін;
- аналіз продажних цін;
- пошук аномалій;
- визначення мінімальної вигідної партії;
- прогнозування закупівель;
- візуалізація ключових показників.
