# Commercial Analysis

AI-assisted інструмент для базового комерційного аналізу продажів, закупівель, маржинальності, покупців і постачальників.

> ⚠️ Проєкт використовує **синтетичні демонстраційні дані**. Реальна комерційна інформація компаній у репозиторії не публікується.

---

## Що робить інструмент

Скрипт `analyze.py` автоматично:

* читає CSV з комерційними даними;
* розраховує виручку;
* розраховує собівартість;
* визначає валовий прибуток;
* розраховує маржу та націнку;
* аналізує товари;
* аналізує категорії;
* формує рейтинг покупців;
* формує рейтинг постачальників;
* виявляє бізнес-ризики;
* визначає рівень ризику та пріоритет;
* генерує короткий управлінський звіт.

## Вхідні дані

Демонстраційний файл:

`examples/demo-komertsiini-dani.csv`

Основні поля:

* дата;
* товар;
* категорія;
* постачальник;
* покупець;
* кількість;
* закупівельна ціна;
* ціна продажу.

## Результати

Після запуску `analyze.py` автоматично створюється папка `output`:

```text
output/
├── commercial-report.csv
├── products-report.csv
├── suppliers-report.csv
├── customers-report.csv
├── alerts-report.csv
└── executive-summary.md
```

### commercial-report.csv

Аналіз за категоріями:

* кількість;
* виручка;
* собівартість;
* валовий прибуток;
* маржа;
* націнка.

### products-report.csv

Рейтинг і показники товарів.

### suppliers-report.csv

Аналіз постачальників та концентрації закупівель.

### customers-report.csv

Рейтинг покупців та концентрації виручки.

### alerts-report.csv

Автоматичні бізнес-сигнали:

* низька маржа;
* висока залежність від покупця;
* висока залежність від постачальника;
* рівень ризику;
* пріоритет;
* рекомендація.

### executive-summary.md

Короткий управлінський звіт:

* KPI;
* ТОП товарів;
* ТОП покупців;
* ТОП постачальників;
* критичні сигнали;
* пріоритетні дії;
* управлінський висновок.

➡️ [Переглянути Executive Summary](output/executive-summary.md)

## Як запустити

Перейти в папку проєкту:

```bash
cd commercial-analysis
```

Запустити:

```bash
python analyze.py
```

Після виконання оновлені звіти автоматично з'являться в папці `output`.

---

## Бізнес-логіка

Поточні контрольні пороги:

| Показник                          |            Поріг |
| --------------------------------- | ---------------: |
| Низька маржа товару               |            < 25% |
| Висока концентрація покупця       |    > 30% виручки |
| Висока концентрація постачальника | > 40% закупівель |

Пороги можна змінювати безпосередньо в `analyze.py`.
