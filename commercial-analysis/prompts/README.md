# Prompts

Робочі AI-промпти для комерційного аналізу.

Тут будуть зберігатися промпти для:

- аналізу продажів;
- аналізу закупівель;
- аналізу постачальників;
- аналізу покупців;
- аналізу маржинальності;
- ABC / XYZ сегментації;
- пошуку аномалій;
- прогнозування закупівель;
- формування управлінських висновків.

## Принцип

Промпти мають бути орієнтовані не на «аналіз заради аналізу», а на отримання конкретного бізнес-рішення.
