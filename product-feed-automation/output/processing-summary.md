## Рекомендації

- **Дубль SKU після нормалізації:** Залишити один актуальний запис для кожного SKU або виправити артикули.
- **Валюта, відмінна від UAH:** Для v1 передавати ціни лише у валюті UAH.
- **Від'ємна ціна:** Перевірити джерело ціни та прибрати від'ємні значення.
- **Від'ємний залишок:** Звірити складські дані та прибрати від'ємні залишки.
- **Відсутній SKU:** Заповнити артикул для кожного товару.
